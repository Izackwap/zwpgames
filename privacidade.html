Política de Privacidade

Última atualização: 13 de novembro de 2026

Esta política explica como o aplicativo ZWPGAMES Clipes ("o aplicativo") trata dados ao usar a API de Dados do YouTube. O aplicativo é uma ferramenta de uso pessoal do dono do canal ZWPGAMES, que roda no computador dele.

1. Uso dos Serviços de API do YouTube

O aplicativo usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google é regido pela Política de Privacidade do Google.

2. Quais dados são acessados

Com a autorização do dono do canal (login do Google via OAuth), o aplicativo recebe um token de acesso com duas permissões:

  • https://www.googleapis.com/auth/youtube.upload: enviar vídeos (título, descrição, tags e arquivo de vídeo) ao canal ZWPGAMES;
  • https://www.googleapis.com/auth/youtube.force-ssl: editar o título e a descrição dos vídeos que o próprio canal ZWPGAMES publicou.

O aplicativo não lê informações da conta, inscritos, comentários, histórico, e-mails nem dados de espectadores ou de outros usuários.

3. Como os dados são usados

O token serve apenas para publicar os vídeos de cortes no canal do próprio usuário que autorizou. Nenhum dado é usado para publicidade, venda, perfilamento ou treino de modelos.

4. Armazenamento e compartilhamento

O token de acesso fica guardado apenas no computador do dono do canal, em arquivo local. Ele não é enviado a servidores próprios nem compartilhado com terceiros. Os únicos dados enviados vão diretamente para o YouTube/Google, para fazer o upload.

O aplicativo não usa cookies nem rastreadores, e este site também não.

5. Como revogar o acesso

A autorização pode ser revogada a qualquer momento na página de permissões de segurança da Conta do Google. Ao revogar, o token deixa de funcionar. O arquivo local pode ser apagado a qualquer momento pelo dono do computador.

6. Retenção e exclusão de dados

O aplicativo guarda localmente apenas: o token de acesso e, para cada vídeo enviado, o ID do vídeo no YouTube e a data do envio (para evitar envios duplicados). Nenhum dado de outros usuários é guardado.

  • Se a autorização for revogada, o aplicativo apaga o token do computador na próxima vez que tentar usá-lo.
  • Além do ID dos vídeos que o próprio canal enviou, nenhum outro dado obtido pela API é guardado. O uso da API segue as Políticas para Desenvolvedores dos Serviços de API do YouTube.
  • Para pedir a exclusão de qualquer dado, escreva para o e-mail de contato abaixo. O pedido é atendido em até 7 dias.

7. Política de Dados do Usuário dos Serviços de API do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

8. Uso da API do TikTok

O aplicativo também publica os mesmos cortes na conta do canal ZWPGAMES no TikTok, usando a Content Posting API do TikTok. Com o login do dono da conta (TikTok Login Kit), ele recebe um token com as permissões:

  • user.info.basic: identificador, nome e foto da própria conta, usados só para confirmar em qual conta postar;
  • video.upload: enviar o vídeo como rascunho para o app do TikTok da própria conta;
  • video.publish: publicar o vídeo na própria conta.

O token do TikTok fica guardado apenas no computador do dono do canal e não é compartilhado. O aplicativo não acessa dados de seguidores, mensagens nem de outras contas. O acesso pode ser revogado a qualquer momento nas configurações de segurança do app do TikTok (gerenciamento de apps conectados); depois disso, o aplicativo apaga o token local na próxima vez que tentar usá-lo. O tratamento de dados pelo TikTok segue a Política de Privacidade do TikTok.

9. Uso da API do Instagram (Meta)

O aplicativo também publica os mesmos cortes como Reels na conta profissional do ZWPGAMES no Instagram, usando a Instagram Graph API da Meta. Com o login do Facebook do dono da conta, ele recebe um token com as permissões instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement e business_management, usadas só para encontrar a Página do Facebook ligada à conta do Instagram do próprio canal e publicar os vídeos nela.

O token fica guardado apenas no computador do dono do canal. O aplicativo não acessa seguidores, mensagens, comentários nem dados de outras contas. O acesso pode ser revogado a qualquer momento nas configurações do Facebook (Configurações > Apps e sites) ou do Instagram; depois disso, o aplicativo apaga o token local quando ele vencer. O tratamento de dados pela Meta segue a Política de Privacidade da Meta.
