Política de Privacidade

Última atualização: 12 de novembro de 2026

Esta política explica como o aplicativo ZWPGAMES Clipes ("o aplicativo") trata dados ao usar a API de Dados do YouTube. O aplicativo é uma ferramenta de uso pessoal do dono do canal ZWPGAMES, que roda no computador dele.

1. Uso dos Serviços de API do YouTube

O aplicativo usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google é regido pela Política de Privacidade do Google.

2. Quais dados são acessados

Com a autorização do dono do canal (login do Google via OAuth), o aplicativo recebe um token de acesso com uma única permissão, https://www.googleapis.com/auth/youtube.upload, usada somente para enviar vídeos (título, descrição, tags e arquivo de vídeo) ao canal ZWPGAMES.

O aplicativo não lê informações da conta, inscritos, comentários, histórico, e-mails nem dados de espectadores ou de outros usuários.

3. Como os dados são usados

O token serve apenas para publicar os vídeos de cortes no canal do próprio usuário que autorizou. Nenhum dado é usado para publicidade, venda, perfilamento ou treino de modelos.

4. Armazenamento e compartilhamento

O token de acesso fica guardado apenas no computador do dono do canal, em arquivo local. Ele não é enviado a servidores próprios nem compartilhado com terceiros. Os únicos dados enviados vão diretamente para o YouTube/Google, para fazer o upload.

O aplicativo não usa cookies nem rastreadores, e este site também não.

5. Como revogar o acesso

A autorização pode ser revogada a qualquer momento na página de permissões de segurança da Conta do Google. Ao revogar, o token deixa de funcionar. O arquivo local pode ser apagado a qualquer momento pelo dono do computador.

6. Política de Dados do Usuário dos Serviços de API do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
